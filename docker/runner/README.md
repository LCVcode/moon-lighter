# Moonlighter Runner Image

This directory defines the V1 Moonlighter Docker runner image.

Local development tag:

```sh
docker build -f docker/runner/Dockerfile -t moonlighter-runner:0.1.0-dev .
```

The image contains:

- Node 22 slim base
- Pi `@earendil-works/pi-coding-agent` pinned by `PI_VERSION`
- Git, Bash, jq, CA certificates
- Python 3 with `python` and `python3`
- `uv`, plus globally available `ruff` and `ty`
- Moon workflow skills copied to `/opt/moon/skills/`

Expected runtime shape:

```text
/workspace                  Moon project root, read/write
/sessions                   persistent Pi session storage, read/write
/home/moon-runtime          generated runtime home, read/write
/home/moon-runtime/.pi/...  minimal Pi auth/settings generated by host Moon
user global skills          mounted read-only when present
/opt/moon/skills            image-bundled Moon workflow skills
```

Moon should run containers as the invoking host UID/GID, set `HOME=/home/moon-runtime`, and prefer:

```text
--read-only
--tmpfs /tmp:rw,exec,nosuid,size=128m
--user $(id -u):$(id -g)
```

Do not mount broad host home, SSH keys, unrelated repositories, the Docker socket, or Moon config/runtime directories into the runner.
